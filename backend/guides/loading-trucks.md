# Loading haul trucks

## Set up the load area

- Agree the truck spotting position and signals with the truck drivers before loading starts.
- Keep the loading area level and clear of spillage.
- Position the machine so the swing (excavator) or travel (wheel loader) distance to the truck is short.

## Loading

1. Wait until the truck has stopped and the driver has signalled they are ready.
2. Never pass the bucket over the truck cab.
3. Load evenly: place the first pass toward the front of the body and spread the rest so the load is centred.
4. Lower the bucket close to the body before dumping so material doesn't slam into it.
5. Don't overload. Follow the truck's rated payload.

## Keeping cycles efficient

- Fill the bucket fully on each pass rather than making extra partial passes.
- Avoid long idle waits with the engine running. If a truck is delayed more than a few minutes, idle down or shut off according to site rules.
